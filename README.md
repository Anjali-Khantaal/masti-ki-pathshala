# मस्ती की पाठशाला

GSSS Mariwara की कक्षा 7 के लिए एक रंगीन, शिक्षक-नियंत्रित और हिंदी-प्रथम
इंटरैक्टिव वेबसाइट।

## अभी क्या तैयार है

- अलग मुखपृष्ठ और **दिन 1** टैब
- तीन क्लिक करके खुलने वाले शिक्षक-परिचय कार्ड
- फ़ोटो, नाम, वर्तमान भूमिका और तीन शौक जोड़ने की सुविधा
- 16 विद्यार्थियों के लिए क्लिक करने योग्य चमकते सितारे
- सभी सितारे पूरे होने पर गुब्बारे, सितारे और तालियों की आवाज़
- लाइट और डार्क मोड
- आवाज़ चालू या बंद करने का नियंत्रण
- सितारों की प्रगति और शिक्षक की जानकारी इसी ब्राउज़र में सुरक्षित

## कक्षा से पहले

1. वेबसाइट खोलें।
2. ऊपर दाईं ओर **मेरी जानकारी** पर क्लिक करें।
3. अपनी फ़ोटो, नाम, वर्तमान भूमिका और शौक भरकर सेव करें।
4. **दिन 1** खोलें और **फिर से शुरू करें** दबाकर सभी सितारे खाली कर दें।
5. Google Meet में इसी ब्राउज़र टैब को साझा करें।

व्यक्तिगत जानकारी किसी सर्वर पर नहीं भेजी जाती। यह केवल उस ब्राउज़र में रहती
है जिसमें जानकारी भरी गई है।

## अपने कंप्यूटर पर चलाएँ

Node.js 22 या नया संस्करण आवश्यक है।

```bash
npm install
npm run dev
```

फिर `http://localhost:3000` खोलें।

## GitHub Pages पर प्रकाशित करें

तैयार static website `docs/` folder में रखी गई है।

1. कोड को GitHub repository की `main` branch पर push करें।
2. GitHub repository में **Settings → Pages** खोलें।
3. **Build and deployment → Source** में **Deploy from a branch** चुनें।
4. Branch में `main` और folder में `/docs` चुनकर **Save** करें।

इस repository के लिए Pages पहले से इसी configuration पर प्रकाशित की गई है।

## जाँच

```bash

```
